# 우물 아래 — The Well Below

숲에서 우물로 **추락**하고, 아이작 스타일의 지하를 헤매다
**"이 모든 것이 꿈(연구 프로젝트)이었다"** 는 반전으로 끝나는 7~8분짜리 2D 탑뷰 웹게임입니다.

`시작하기`를 누르면 **타임어택 모드**와 **일반 모드** 중에서 고를 수 있습니다.

HTML · CSS · 순수 JavaScript(Canvas 2D)로만 만들었고, 외부 라이브러리가 없습니다.

---

## ▶ 실행 방법

### 가장 쉬운 방법 — 단일 파일
`dist/우물아래.html` **한 파일만 내려받아 더블클릭**하면 됩니다.
CSS·JS·이미지가 전부 안에 들어 있어서 인터넷도, 서버도 필요 없습니다.

### 개발용 (파일이 나뉜 버전)
저장소를 받은 뒤 `index.html` 을 브라우저로 열면 그대로 실행됩니다.
수정한 내용을 단일 파일로 다시 묶으려면:

```bash
python3 build.py      # → dist/우물아래.html 생성
```

> 권장 브라우저: Chrome / Edge / Firefox 최신 버전. 소리는 화면을 한 번 클릭해야 켜집니다.

## ⏱ 타임어택

사람들끼리 기록으로 겨루기 위한 모드입니다.

| | |
|---|---|
| **측정 구간** | `시작` 버튼을 누른 순간 → 마지막 문에 열쇠를 꽂는 순간 |
| **표시** | HUD 오른쪽 위에 `0:00.00` (1/100초 단위) |
| **엔딩 정산** | 클리어 타임 + 상위 3위 기록, 최고 기록이면 `NEW RECORD` |
| **기록 보관** | 브라우저 `localStorage` 에 상위 5개 (기기별로 저장) |

### 컷신 없이 엔딩만

기록 경쟁이라, 시계를 잡아먹는 연출은 전부 건너뜁니다. 엔딩만 그대로 나옵니다.

- 1인칭 오프닝 (잠드는 장면 · 숲에서 눈뜨기) → 곧장 탑뷰 숲
- 숲의 첫 독백, 방에 처음 들어설 때의 독백, 첫 글리치 독백
- 우물 추락 · 착지 · 1인칭 눈뜨기 → 우물을 조사하면 곧장 지하 첫 방
- 눈 보스 등장 연출 → 보스방에 들어서면 바로 전투
- 눈이 먹히는 변이 장면과 심연이 솟는 변신 컷신 → 그 자리에서 바로 심연
  (구급 팩 체력칸은 즉시 적용, 심연 브금은 조용한 도입을 건너뛰고 본편부터)
- 심연의 최후 컷신 → 시체만 남고 마지막 열쇠가 바로 손에
- 보스 처치 대사와 마지막 자물쇠 대사 → 자물쇠를 조사하면 곧장 엔딩

> 이 변경 전의 기록은 컷신 시간이 포함된 기록입니다.

### 죽으면 그대로 끝입니다

- 방 재시작이 **없습니다.** 사망하면 즉시 세션이 종료됩니다.
- 사망 화면에 **생존 시간**만 보여주고, **기록은 저장되지 않습니다.**
- `R` 또는 버튼을 누르면 **열쇠·방문 기록·정리한 방이 전부 초기화**되고
  타이틀로 돌아갑니다. 다음 판은 완전히 처음부터입니다.

### 기록 관리

```js
__game.loadRecords()    // 저장된 기록 (ms 배열)
__game.clearRecords()   // 기록 전체 삭제
```

> 여러 명이 한 기기에서 돌아가며 할 때는, 판이 끝날 때마다 화면의
> 클리어 타임을 적어두는 편이 편합니다. 기록표는 기기 하나에 공유됩니다.

## 🗺 복선(떡밥) 연결 고리

지하에서 마주치는 기괴한 요소는 전부 **현실(연구실)의 사물이 왜곡된 것**입니다.
엔딩에서 카메라가 심전도 모니터 밖으로 물러나면 이것들이 한 방에 다 드러납니다.
전극선의 색이 청·적·황·백이라, 던전을 물들인 오방색도 여기서 온 셈입니다.

| 지하 던전 (꿈) | 현실 연구실 (진짜 모습) |
|---|---|
| 바닥에 흩어진 해골과 뼈 | 구석에 쌓여 있는 인체 골격 모형 |
| 사방에 흩뿌려진 피와 핏방울 | 몸에 꽂힌 링거 호스와 붉은 배양액 |
| 방을 잠그는 '열쇠'와 '상자' | 실험 장치의 '키카드'와 '잠금장치' |
| 기괴한 몬스터 / 슬라임 | 모니터에 출력되는 뇌파 그래프·세포 이미지 |
| 던전 벽의 단청 격자 | 천장 조명 격자 |

### 게임 안에 심어 둔 장치

- **지상의 이질감** — 평화로운 새소리 밑에 환풍기 소리가 계속 깔리고, 아주 가끔
  숲과 어울리지 않는 **기계 비프음**이 울립니다. 나비도 이따금 한 프레임 **튑니다**.
- **날짜가 뛴다** — **처음 밟는 방**마다 HUD의 `LOG DATE` 와 벽 낙서가
  `5/1 → 5/3 → 5/5 → … → 5/20` 으로 건너뜁니다.
  *"내가 길을 잃은 게 아니라, 시간이 흐르며 실험이 깊어지고 있다."*
- **시스템 에러** — 몬스터를 처치하면 피가 튀는 대신 **노이즈와 함께 코드 조각·뇌파
  그래프**로 흩어집니다.
- **무너지는 단청** — 오방색 단청 무늬가 깊이 내려갈수록 흐려지고 각도가 어긋납니다.
- **빛나는 버섯** — 벽과 바닥에 자라난 발광 버섯이 통로를 은은하게 비춥니다.
  깊이 들어갈수록 단청이 흐려지고 어긋납니다.
- **쪽지 3장** — 기획안의 2145/5/1, 2145/5/15 쪽지에 더해, 헤매는 행위 자체를
  짚는 5/18 쪽지가 관문에 있습니다.

## 🗺 맵 구조 — 갈라졌다가 다시 만나는 길

방은 격자 좌표에 놓이고, **맞닿은 방끼리 자동으로 문이 생깁니다.**
갈림길에서 세 갈래로 퍼진 뒤 '중앙'과 '관문'에서 하나로 합쳐지므로,
**길을 헤매도 결국 같은 출구**에 도달합니다.

```
           [북]───[북동]
            │        │
[시작]──[갈림길]──[중앙]──[관문]──[보스]──[탈출]
            │        │
           [남]───[남동]
```

| 방 | 내용 | 얻는 것 |
|---|---|---|
| 시작 | 착지 지점 | — |
| 갈림길 | 세 갈래 분기 | — |
| **북** | 잡몹 4 | **관문 열쇠 ①** |
| 남 | 잡몹 2 · 바닥 열쇠 | 상자 → **쪽지 1** + 하트 |
| 북동 | 잡몹 3 · 전멸 시 열쇠 | 상자 → 하트 |
| 중앙 | 잡몹 3 · 바닥 열쇠 | 상자 → **쪽지 2** + 하트 |
| **남동** | 잡몹 4 | **관문 열쇠 ②** |
| 관문 | 잠금장치 2개 | 상자 → **쪽지 3** + 하트 |
| 보스 | 눈 (3페이즈) | 마지막 열쇠 |
| 탈출 | 거대한 문 | **엔딩** |

- **관문은 열쇠 2개**가 있어야 열립니다 → 북·남동 두 갈래를 반드시 밟게 됩니다.
- 나머지 갈래(남·북동·중앙)는 **쪽지와 회복**을 주는 선택 경로입니다.
- 방의 적을 모두 없애야 다음 방으로 넘어갈 수 있고, **한 번 정리한 방은
  다시 들어가도 비어 있습니다.**
- 우하단 **미니맵**에 지나온 방과 갈 수 있는 방이 표시됩니다.

### ⏱ 날짜가 뛴다 (핵심 복선)

날짜는 스테이지가 아니라 **처음 밟는 방의 개수**를 따라갑니다.

```
5/1 → 5/3 → 5/5 → 5/8 → 5/10 → 5/12 → 5/15 → 5/17 → 5/18 → 5/20
```

헤맬수록 날짜가 앞으로 가므로, *"내가 길을 잃은 게 아니라 실험이 깊어지고 있다"* 는
감각이 생깁니다. 관문의 **쪽지 3**이 이걸 직접 짚어 줍니다.

## ⚖️ 밸런스 (플레이 타임 7~8분 기준)

수치는 전부 `js/rooms.js` 의 `BALANCE` 에 모아 두었습니다.

| 항목 | 값 | 비고 |
|---|---|---|
| **플레이어 체력** | **하트 3개** | 피격 후 1.1초 무적 · 죽으면 판 종료 |
| 이동 속도 | 2.15 px/f | 약 129 px/s |
| 연사 | 20프레임 | 초당 3발, 발당 1 데미지 |
| 버섯 | HP 3 / 속도 0.70 | 근접 추격 |
| 포자 버섯 | HP 4 / 속도 0.45 | 2.3초마다 포자, 거리 유지 |
| **보스(눈)** | **HP 78** | 하트 3개 기준 **60~75초** |

**회복 수단** — 체력이 3칸뿐이라 보급을 넉넉히 뒀습니다.

- **상자 4개**가 각각 하트를 하나씩 내놓습니다 (남 · 북동 · 중앙 · 관문)
- 항아리는 50% 확률로 하트를 떨어뜨립니다
- 보스는 **페이즈가 바뀔 때마다** 체력이 깎여 있으면 하트를 하나 흘립니다

**보스 3단계 구성**

1. **1페이즈 (100~66%)** — 느린 추격 + 약 2.3초마다 10방향 포자. 예고 동작 32프레임.
2. **2페이즈 (66~33%)** — 14방향 포자에 **돌진**이 섞임. 속도 1.15배.
3. **3페이즈 (33~0%)** — 속도 1.5배, **나선탄** 지속 발사, 잡몹 2마리 소환.

### 진행 시간 배분

```
숲 40s → 던전 9개 방 × 약 40s ≈ 6분 → 보스 70s   ≒ 7분 30초  (여기까지가 기록)
                                        + 엔딩 연출 약 30s (측정 제외)
```

숙련되면 6분대, 길을 헤매면 9분 이상까지 벌어집니다.

## 🔆 밝기 조절

**맵(숲·던전)은 어둡게, UI(HUD·타이틀·자막 등)는 밝게** — 이 둘을 분리해서 관리합니다.

| 위치 | 설명 |
|---|---|
| `js/game.js` 의 `drawNightOverlay(...)` 두 줄 | 맵의 어둠 강도 (`0` = 어둠 없음). 캔버스 안, HUD 에는 영향 없음 |
| `js/art.js` 의 `bakeForest` / `bakeDungeonFloor` 팔레트 | 맵 바닥·풀 색상 |
| `css/style.css` | HUD·타이틀·자막·쪽지 등 캔버스 바깥 UI (별도 유지) |

```js
drawNightOverlay(g, W, H, P.x, P.y, .34, 172);                  // 숲
drawNightOverlay(g, W, H, P.x, P.y, .40 + G.depth * .022, 150);  // 던전
```

## 🔊 소리 크기

전체적으로 잘 안 들린다는 피드백에 맞춰 볼륨을 크게 올렸습니다.

- 마스터 게인 `0.5 → 1.35`, 겹쳐 울릴 때 깨지지 않도록 리미터(컴프레서) 추가
- 효과음 대부분을 1.7~2배가량 증폭 (발소리·새소리·기계 비프처럼 원래 작던 소리는 그 이상)
- 배경 앰비언스(환풍기/드론음)도 함께 키움

`js/audio.js` 상단 `master.gain.value` 한 곳에서 전체 크기를 다시 조절할 수 있습니다.

### iPhone · iPad 무음 모드

iOS 사파리는 웹 게임 소리를 알림음처럼 다뤄서, **무음 모드면 내장 스피커로는 소리가
나지 않습니다** (이어폰은 들림). 그래서 화면을 처음 건드리는 순간 이 페이지를
"미디어 재생"으로 바꿔, 동영상처럼 무음 모드에서도 들리게 합니다.

- iOS 17 이상 : `navigator.audioSession.type = 'playback'`
- 그보다 오래된 iOS : 무음 `<audio>` 를 반복 재생해 두는 방식
- 손가락을 뗄 때(`touchend`)도 소리를 깨우고, 다른 앱에 다녀와 멈춘(`interrupted`)
  소리도 다음 터치에 다시 켭니다.

## 🩸 보스 컷신 (일반 모드)

**변이 — 눈이 심연에게 먹히는 장면 (약 5.5초)**
눈을 쓰러뜨리면 그 자리에 굳어 하얗게 번쩍인 뒤, 점점 빨라지는 박동과 함께
보랏빛이 핏빛으로 번지고 흰자위에 붉은 금이 퍼집니다. 바닥이 갈라지며 촉수가
올라와 눈을 휘감고, 안쪽에서 녹슨 쇠갈고리(심연의 낫·집게)가 뚫고 나옵니다.
뿔 달린 껍데기가 산산조각 나면 맨 눈알만 남고, 촉수가 그것을 바닥 속으로
끌어내립니다. 그 뒤로 기존의 암전 · 관측 로그 · 솟아오르는 심연이 이어집니다 —
심연 가슴 한가운데의 붉은 눈이 바로 그 눈입니다.

**심연의 최후 (약 10초)**
마지막 일격에 화면이 얼어붙고, 심연이 포효하며 발악합니다. 몸 곳곳이 글리치로
터지고 검붉은 체액이 튀다가, 왼팔의 낫이 뜯겨 나가 바닥에 나뒹굴고 집게가 축
늘어집니다. 몸이 주저앉으며 체액이 고이고, 가슴의 눈이 마지막으로 터지며 꺼집니다.
정적 속에 연기가 피어오르고 한 번 경련한 뒤, 시체에서 마지막 열쇠가 떠올라
주인공에게 날아옵니다. **시체는 그대로 남아**, 방을 나갔다 와도 그 자리에 있습니다.

## 🌅 오프닝 — 1인칭으로 시작 (일반 모드)

엔딩(실험실에서 깨어남)과 짝을 이루는 첫 장면입니다. 무엇인지 말해 주지는
않습니다 — 엔딩을 보고 나서야 그게 무엇이었는지 알게 됩니다.

1. **잠드는 쪽 (약 46초)** — 졸린 눈으로 올려다본 흰 천장과 격자 조명. 귀에 들어오는 건
   대화의 조각뿐입니다. 대화는 천천히 들려줍니다 (`js/game.js` 의 `OP_SLOW` 로 빠르기 조절). 가까운 목소리(의사), 저쪽의 작은 목소리(조수), 짧은 지시 하나.

   | 목소리 | 대사 | 화면 |
   |---|---|---|
   | 가까이 | `…들리세요?` | 가장자리에서 들여다보는 머리, 안경알 |
   | 저쪽 | `반응 있어요. 동공이 느리고.` | 펜라이트가 눈을 훑고 눈꺼풀이 움찔 |
   | 가까이 | `괜찮아요. 오늘도 금방 끝나요.` | |
   | 가까이 | `…141번째예요. 기억 안 나시겠지만.` | (엔딩의 SESSION 141) |
   | 저쪽 (다급) | `수치 튀어요 — 깨려고 해요!` | **⚡ 각성** — 눈이 번쩍 뜨이고 초점이 잡힘, 경보음, 화면이 붉게 맥박침, 또 한 사람이 뛰어옴 |
   | 가까이 | `쉬이… 괜찮아요. 괜찮아요.` | 의사가 바짝 들여다봄 (안경알 두 개) |
   | 지시 | `용량 올려.` | **💉 약이 들어감** — 차가운 푸른 물결이 아래서부터 차오르고 상이 두 겹으로 갈라진 뒤 눈꺼풀이 무너짐 |
   | 가까이 | `자, 오늘은 우물 이야기를 해 드릴게요.` · `숲 끝에, 오래된 우물이 하나 있어요.` · `그 아래로… 천천히 내려가 보는 거예요.` | |
   | 가까이 | `숫자를 거꾸로 세어 보세요.` `10.` `9.` `8.` `7…` (하나에 약 1.4초) | **🕳 하강** — 천장이 멀어지며 돌로 쌓은 통로가 시야를 둘러쌈. 병실 천장이 우물 입구가 됨. `7…` 에서 바닥이 꺼지듯 툭 떨어지고 눈이 감김 |

## 🎬 엔딩 연출 순서

마지막 자물쇠의 대사가 네 박자로 끊기며, 한 줄마다 화면이 한 단계씩 더 무너집니다.

| 대사 | 화면 |
|---|---|
| `열쇠를 꽂는다. 딸깍.` | 딸깍 소리, 살짝 흔들림 |
| `…방이 **일그러진다.**` | 방이 물결처럼 일렁이기 시작 |
| `아니.` | 숨을 죽이듯 거의 멈춤 |
| `**화면이** 일그러진다.` | 화면이 찢어지고 색이 갈라짐 → 그대로 붕괴로 |

연출은 전부 `js/ending.js` 의 캔버스 한 장에서 그립니다 (라이브러리 없음).

1. **현실 붕괴 (약 5초)** — 마지막 열쇠를 꽂은 그 방이 그대로 글리치로 무너진다.
   띠 밀림 · RGB 분리 · 노이즈가 차오르다 화면이 가로로 찢어지며 하얗게 날아가고,
   브라운관이 꺼지듯 선 → 점 → 정적.
2. **바이탈 (약 6.5초)** — 칠흑 속에 심전도 선이 그어진다. 던전의 형광 청록으로
   시작한 선이 첫 박동의 `삐—` 와 함께 터미널 녹색으로 식어 간다.
3. **모니터 밖 (약 6초)** — 카메라가 물러나면 그 심전도는 벽에 걸린 모니터였다.
   어두운 방엔 모니터 빛과 관찰창의 실루엣만 보이다가, 형광등이 두어 번 튀고
   켜지며 실험실이 드러난다 — 침대에 누운 피험자, 뇌파 캡과 오방색 전극선,
   링거와 붉은 배양액, 골격 모형, 키카드 잠금장치, 관찰창 너머의 연구원.
4. **진실** — 터미널에 한 글자씩 찍힌다.
   `수면 상태 해제 중...` → `뇌파 연결 차단 완료.` →
   `수면 실험 종료. 피험자 07번, 의식 회복 확인.`
   다 찍히면 카메라가 얼굴로 다가가고, 짧은 숨소리와 함께 **피험자가 눈을 뜬다**.
   심박이 60 → 78 로 빨라진다.
5. 깜빡이는 커서와 `PRESS SPACE TO RETURN` → SPACE 를 누르면 `THE END` 카드
   (타임어택이면 클리어 타임과 상위 3위 기록)

`prototypes/ending.html` 은 같은 `js/ending.js` 로 엔딩만 따로 돌려 보는 페이지입니다.
게임 화면 대신 무너지는 눈 보스(대역 던전)로 시작합니다.
`python3 build.py` 가 이것도 `dist/우물아래_엔딩.html` 한 파일로 묶습니다.

### 잡몹 만들기

"메이플 버섯처럼 귀엽다"는 인상을 없애기 위해 `tools/make_assets.py` 가
원본을 다음 순서로 가공합니다.

1. 버섯 **대(얼굴) 영역**을 연결 요소로 찾고
2. 그 안쪽에 **갇힌 구멍**(동그란 눈 · 미소 · 볼터치)만 살색으로 메운 뒤
   — 갓의 어두운 밑면은 바깥과 이어져 있으므로 건드리지 않습니다
3. 전체를 어둡게 낮추고 보랏빛 슬레이트로 물들이고
4. **처진 눈매 · 붉은 홍채 · 톱니 이빨**을 픽셀로 다시 그립니다

게임에서는 여기에 **어둠 속에서 번들거리는 눈빛**과 발밑의 기운을 얹습니다.

```bash
python3 tools/make_assets.py <업로드폴더>   # assets/*.png + js/assets.js 재생성
```

기둥 · 서류장 뒤로 돌아가면 가려집니다. 문 앞길과 적 · 상자 · 열쇠 자리는 비워 두었고,
모든 방에서 문 · 상자 · 열쇠까지 길이 이어지는지 길 찾기로 확인했습니다.

눈과 싸우다 죽으면 지금처럼 보스방 처음부터, 타임어택은 언제나 처음부터입니다.

쉬움의 보스는 페이즈2·3을 **같은 폭으로** 낮췄습니다 (각각 체력 −15% 를 더하고 위 배율을 똑같이).

### 넓어진 보스방

보스방(심층)만 화면(576×324)보다 넓은 **768×432** 입니다 (`js/rooms.js` 의 `size`). 방이 화면보다
넓으면 카메라가 주인공을 따라가되 보스 쪽으로 30% 당겨서 보스가 되도록 화면 안에 있게 하고,
보스 등장 · 변이 · 심연의 최후 동안엔 그 자리 쪽을 봅니다. 미니맵 · 보스 체력바 · 섬광 같은
화면 위의 것은 그대로 화면에 붙어 있습니다. 바닥의 둥근 의식 원 · 케이블 · 항아리 자리도 방 크기에 맞춰 넓어졌습니다.

피할 자리가 늘어난 만큼 보스 패턴을 세 난이도 모두 **살짝** 올렸습니다 — 눈 · 심연 속도 +10%,
공격 간격 ×0.92(보통 기준), 탄속 ×1.06, 눈의 원형 포자 +2발. 예비 동작(피할 틈)과 체력은 그대로입니다.
어려움은 여기에 공격 간격 · 탄속 · 나선탄을 한 걸음 더, 쉬움은 예전보다 조금만 덜 느긋하게 했습니다.
