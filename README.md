# 우물 아래 — The Well Below

숲에서 우물로 **추락**하고, 아이작 스타일의 지하를 헤매다
**"이 모든 것이 꿈(연구 프로젝트)이었다"** 는 반전으로 끝나는 7~8분짜리 2D 탑뷰 웹게임입니다.

`시작하기`를 누르면 **타임어택 모드**와 **일반 모드** 중에서 고를 수 있습니다.

HTML · CSS · 순수 JavaScript(Canvas 2D)로만 만들었고, 외부 라이브러리가 없습니다.

---

## ▶ 실행 방법

### 가장 쉬운 방법 — 단일 파일
`dist/우물아래.html` **한 파일만 내려받아 더블클릭**하면 됩니다.
CSS·JS·이미지가 전부 안에 들어 있어서 인터넷도, 서버도 필요 없습니다.

### 개발용 (파일이 나뉜 버전)
저장소를 받은 뒤 `index.html` 을 브라우저로 열면 그대로 실행됩니다.
수정한 내용을 단일 파일로 다시 묶으려면:

```bash
python3 build.py      # → dist/우물아래.html 생성
```

> 권장 브라우저: Chrome / Edge / Firefox 최신 버전. 소리는 화면을 한 번 클릭해야 켜집니다.

## ⏱ 타임어택

사람들끼리 기록으로 겨루기 위한 모드입니다.

| | |
|---|---|
| **측정 구간** | `시작` 버튼을 누른 순간 → 마지막 문에 열쇠를 꽂는 순간 |
| **표시** | HUD 오른쪽 위에 `0:00.00` (1/100초 단위) |
| **엔딩 정산** | 클리어 타임 + 상위 3위 기록, 최고 기록이면 `NEW RECORD` |
| **기록 보관** | 브라우저 `localStorage` 에 상위 5개 (기기별로 저장) |

### 컷신 없이 엔딩만

기록 경쟁이라, 시계를 잡아먹는 연출은 전부 건너뜁니다. 엔딩만 그대로 나옵니다.

- 1인칭 오프닝 (잠드는 장면 · 숲에서 눈뜨기) → 곧장 탑뷰 숲
- 숲의 첫 독백, 방에 처음 들어설 때의 독백, 첫 글리치 독백
- 우물 추락 · 착지 · 1인칭 눈뜨기 → 우물을 조사하면 곧장 지하 첫 방
- **우물 바닥에서 눈뜨기 소리** — 눈꺼풀이 실제로 움직이기 시작하는 순간에 맞춰, 뜰 땐 붙었던 눈꺼풀이 떨어지는
  젖은 '쩍'(짧은 틱 두어 개) + 속눈썹이 스치는 바람 + 들이쉼, 감길 땐 부드러운 '스윽…톡' + 내쉼. 크게 뜰수록 크게.
  떨어진 충격의 **귀울림**(높은 삐이)이 눈을 뜰수록 잦아들어 다 뜨면 사라지고, 그동안 **먹먹한 심장**이 처음엔
  빠르게, 정신이 들수록 느리게 뜁니다.
- 눈 보스 등장 연출 → 보스방에 들어서면 바로 전투
- 눈이 먹히는 변이 장면과 심연이 솟는 변신 컷신 → 그 자리에서 바로 심연
  (구급 팩 체력칸은 즉시 적용, 심연 브금은 조용한 도입을 건너뛰고 본편부터)
- 심연의 최후 컷신 → 시체만 남고 마지막 열쇠가 바로 손에
- 보스 처치 대사와 마지막 자물쇠 대사 → 자물쇠를 조사하면 곧장 엔딩

> 이 변경 전의 기록은 컷신 시간이 포함된 기록입니다.

### 죽으면 그대로 끝입니다

- 방 재시작이 **없습니다.** 사망하면 즉시 세션이 종료됩니다.
- 사망 화면에 **생존 시간**만 보여주고, **기록은 저장되지 않습니다.**
- `R` 또는 버튼을 누르면 **열쇠·방문 기록·정리한 방이 전부 초기화**되고
  타이틀로 돌아갑니다. 다음 판은 완전히 처음부터입니다.

### 기록 관리

```js
__game.loadRecords()    // 저장된 기록 (ms 배열)
__game.clearRecords()   // 기록 전체 삭제
```

> 여러 명이 한 기기에서 돌아가며 할 때는, 판이 끝날 때마다 화면의
> 클리어 타임을 적어두는 편이 편합니다. 기록표는 기기 하나에 공유됩니다.

## 🗺 복선(떡밥) 연결 고리

지하에서 마주치는 기괴한 요소는 전부 **현실(연구실)의 사물이 왜곡된 것**입니다.
엔딩에서 카메라가 심전도 모니터 밖으로 물러나면 이것들이 한 방에 다 드러납니다.
전극선의 색이 빨강·파랑·노랑·흰색이라, 던전을 물들인 오방색도 여기서 온 셈입니다.

| 지하 던전 (꿈) | 현실 연구실 (진짜 모습) |
|---|---|
| 바닥에 흩어진 해골과 뼈 | 구석에 쌓여 있는 인체 골격 모형 |
| 사방에 흩뿌려진 피와 핏방울 | 몸에 꽂힌 링거 호스와 붉은 배양액 |
| 방을 잠그는 '열쇠'와 '상자' | 실험 장치의 '키카드'와 '잠금장치' |
| 기괴한 몬스터 / 슬라임 | 모니터에 출력되는 뇌파 그래프·세포 이미지 |
| 던전 벽의 단청 격자 | 천장 조명 격자 |

### 게임 안에 심어 둔 장치

- **지상의 이질감** — 평화로운 새소리 밑에 환풍기 소리가 계속 깔리고, 아주 가끔
  숲과 어울리지 않는 **기계 비프음**이 울립니다. 나비도 이따금 한 프레임 **튑니다**.
- **날짜가 뛴다** — **처음 밟는 방**마다 HUD의 `LOG DATE` 와 벽 낙서가
  `5/1 → 5/3 → 5/5 → … → 5/20` 으로 건너뜁니다.
  *"내가 길을 잃은 게 아니라, 시간이 흐르며 실험이 깊어지고 있다."*
- **시스템 에러** — 몬스터를 처치하면 피가 튀는 대신 **노이즈와 함께 코드 조각·뇌파
  그래프**로 흩어집니다.
- **무너지는 단청** — 오방색 단청 무늬가 깊이 내려갈수록 흐려지고 각도가 어긋납니다.
- **빛나는 버섯** — 벽과 바닥에 자라난 발광 버섯이 통로를 은은하게 비춥니다.
  깊이 들어갈수록 단청이 흐려지고 어긋납니다.
- **쪽지 3장** — 기획안의 2145/5/1, 2145/5/15 쪽지에 더해, 헤매는 행위 자체를
  짚는 5/18 쪽지가 관문에 있습니다.

## 🗺 맵 구조 — 갈라졌다가 다시 만나는 길

방은 격자 좌표에 놓이고, **맞닿은 방끼리 자동으로 문이 생깁니다.**
갈림길에서 세 갈래로 퍼진 뒤 '중앙'과 '관문'에서 하나로 합쳐지므로,
**길을 헤매도 결국 같은 출구**에 도달합니다.

```
           [북]───[북동]
            │        │
[시작]──[갈림길]──[중앙]──[관문]──[보스]──[탈출]
            │        │
           [남]───[남동]
```

| 방 | 내용 | 얻는 것 |
|---|---|---|
| 시작 | 착지 지점 | — |
| 갈림길 | 세 갈래 분기 | — |
| **북** | 잡몹 4 | **관문 열쇠 ①** |
| 남 | 잡몹 2 · 바닥 열쇠 | 상자 → **쪽지 1** + 하트 |
| 북동 | 잡몹 3 · 전멸 시 열쇠 | 상자 → 하트 |
| 중앙 | 잡몹 3 · 바닥 열쇠 | 상자 → **쪽지 2** + 하트 |
| **남동** | 잡몹 4 | **관문 열쇠 ②** |
| 관문 | 잠금장치 2개 | 상자 → **쪽지 3** + 하트 |
| 보스 | 눈 (3페이즈) | 마지막 열쇠 |
| 탈출 | 거대한 문 | **엔딩** |

- **관문은 열쇠 2개**가 있어야 열립니다 → 북·남동 두 갈래를 반드시 밟게 됩니다.
- 나머지 갈래(남·북동·중앙)는 **쪽지와 회복**을 주는 선택 경로입니다.
- 방의 적을 모두 없애야 다음 방으로 넘어갈 수 있고, **한 번 정리한 방은
  다시 들어가도 비어 있습니다.**
- **방에 들어서는 순간은 안전하게** — 들어온 문에서 120px 안쪽에 선 적은 그 밖으로 물러나 있고(북쪽 방의 버섯은
  문에서 26px 이라 들어서자마자 부딪혔습니다), 들어선 직후 잠깐은 아무도 쏘지 않습니다.
- 우하단 **미니맵**에 지나온 방과 갈 수 있는 방이 표시됩니다.

### ⏱ 날짜가 뛴다 (핵심 복선)

날짜는 스테이지가 아니라 **처음 밟는 방의 개수**를 따라갑니다.

```
5/1 → 5/3 → 5/5 → 5/8 → 5/10 → 5/12 → 5/15 → 5/17 → 5/18 → 5/20
```

헤맬수록 날짜가 앞으로 가므로, *"내가 길을 잃은 게 아니라 실험이 깊어지고 있다"* 는
감각이 생깁니다. 관문의 **쪽지 3**이 이걸 직접 짚어 줍니다.

## ⚖️ 밸런스 (플레이 타임 7~8분 기준)

수치는 전부 `js/rooms.js` 의 `BALANCE` 에 모아 두었습니다.

| 항목 | 값 | 비고 |
|---|---|---|
| **플레이어 체력** | **하트 3개** | 피격 후 1.1초 무적 · 죽으면 판 종료 |
| 이동 속도 | 2.15 px/f | 약 129 px/s |
| 연사 | 20프레임 | 초당 3발, 발당 1 데미지 |
| 버섯 | HP 3 / 속도 0.70 | 근접 추격 |
| 포자 버섯 | HP 4 / 속도 0.45 | 2.3초마다 포자, 거리 유지 |
| **보스(눈)** | **HP 77** | 하트 3개 기준 **65~75초** (보통) |

**회복 수단** — 체력이 3칸뿐이라 보급을 넉넉히 뒀습니다.

- **상자 4개**가 각각 하트를 하나씩 내놓습니다 (남 · 북동 · 중앙 · 관문)
- 항아리는 50% 확률로 하트를 떨어뜨립니다
- 보스는 **페이즈가 바뀔 때마다** 체력이 깎여 있으면 하트를 하나 흘립니다

**보스 3단계 구성**

1. **1페이즈 (100~66%)** — 추격 + 약 2초마다 12방향 포자. 예고 동작 29프레임. (보통 기준)
2. **2페이즈 (66~33%)** — 16방향 포자 **두 겹**에 **돌진**이 섞임. 속도 1.15배.
3. **3페이즈 (33~0%)** — 속도 1.5배, **나선탄** 지속 발사, 잡몹 2마리 소환.

### 진행 시간 배분

```
숲 40s → 던전 9개 방 × 약 40s ≈ 6분 → 보스 70s   ≒ 7분 30초  (여기까지가 기록)
                                        + 엔딩 연출 약 30s (측정 제외)
```

숙련되면 6분대, 길을 헤매면 9분 이상까지 벌어집니다.

## 🔆 밝기 조절

**맵(숲·던전)은 어둡게, UI(HUD·타이틀·자막 등)는 밝게** — 이 둘을 분리해서 관리합니다.

| 위치 | 설명 |
|---|---|
| `js/game.js` 의 `drawNightOverlay(...)` 두 줄 | 맵의 어둠 강도 (`0` = 어둠 없음). 캔버스 안, HUD 에는 영향 없음 |
| `js/art.js` 의 `bakeForest` / `bakeDungeonFloor` 팔레트 | 맵 바닥·풀 색상 |
| `css/style.css` | HUD·타이틀·자막·쪽지 등 캔버스 바깥 UI (별도 유지) |

```js
drawNightOverlay(g, W, H, P.x, P.y, .34, 172);                  // 숲
drawNightOverlay(g, W, H, P.x, P.y, .40 + G.depth * .022, 150);  // 던전
```

`js/audio.js` 상단 `master.gain.value` 한 곳에서 전체 크기를 다시 조절할 수 있습니다.

### iPhone · iPad 무음 모드

iOS 사파리는 웹 게임 소리를 알림음처럼 다뤄서, **무음 모드면 내장 스피커로는 소리가
나지 않습니다** (이어폰은 들림). 그래서 화면을 처음 건드리는 순간 이 페이지를
"미디어 재생"으로 바꿔, 동영상처럼 무음 모드에서도 들리게 합니다.

- iOS 17 이상 : `navigator.audioSession.type = 'playback'`
- 그보다 오래된 iOS : 무음 `<audio>` 를 반복 재생해 두는 방식
- 손가락을 뗄 때(`touchend`)도 소리를 깨우고, 다른 앱에 다녀와 멈춘(`interrupted`)
  소리도 다음 터치에 다시 켭니다.

**오프닝은 탈출과 같은 실사 3D** 입니다 (`js/opening3d.js` + `js/labroom.js` + `js/figure3d.js`, WebGL).
눈꺼풀 · 흐림 · 경보의 붉은 맥박 · 약의 푸른 물결 · 목소리 글자는 그 위에 얹습니다.

- **실험실** — 엔딩 · 탈출의 그 방, 그 침대에 누워 올려다본 천장(격자 조명 · 환기구 · 문틀 · 심전도 모니터).
  들여다보는 의사는 3D 방호복 — 각성하면 바짝 다가오고 붉은 빛이 방호복에 번집니다 (조수는 목소리로만).
- **우물 하강** — 숫자를 세는 동안 돌을 쌓은 우물 통로 바닥으로 가라앉습니다. 처음엔 방금까지 보던 실험실 천장이
  화면 그대로 겹쳐 있다가, 내려갈수록 그 천장이 저 위 우물 입구 속에 비친 작은 빛이 됩니다 (깊을수록 이끼 낀 돌, 시야가 천천히 돎).
- **숲** — 땅에 누워 올려다본 나무줄기 · 가지 · 잎 덩어리와 해 질 녘 하늘(해 둘레 빛무리, 바람에 살랑이는 잎),
  가지 틈에서 노을을 등진 3D 방호복이 내려다봅니다. 첫 깜빡임 사이로 비치는 건 그 실험실 천장 그대로. 몸을 일으키면 시선이 하늘에서 숲 앞으로 내려옵니다.
- **글리치** — 실험실이 또렷이 보이는 순간마다 화면이 잠깐 찢어지고(가로 띠 밀림) · 색이 어긋나고(빨강만 옆으로) ·
  **픽셀 그림으로 무너졌다가**(몇 단계 색의 큰 픽셀 — 이어지는 탑뷰 본편과 같은 결) · 위아래로 미끄러지거나 깨진 조각이 끼어듭니다.
  색 반전 · 한 장에 걸려 멈춤 · 신호가 끊긴 듯 새까만 프레임도 섞입니다. 세게 — 6‥22 프레임, 몇 초마다. 소리는 전파가 끊긴 TV 같은 **치지직 잡음**(`Sfx.static`) — 무겁지 않게 얇고 높은 "직 · 지직"(2.4kHz 위만, 반쯤은 비어 듬성듬성, 길어도 0.16초).
  크게 들여다볼 때 · 각성 · `7…` 의 툭에서 가장 크고(화면도 흔들림), 그 사이사이 한두 프레임짜리 잔글리치가 자주 스칩니다 (`js/game.js` 의 `OP_GLITCH` · `OP_GLITCH_WOOD` 표).

- 느린 기기 — 한 장 그리는 간격이 길면 3D 해상도를 낮추고(최저 0.7배), 넉넉해지면 되돌립니다(최고 1.8배) — 방호복도 같은 배율로.
- **컷신 3D 화질** — 방호복은 실험실과 같은 고해상도(1728×972)로 바로 그립니다 (예전엔 960×540 을 늘려 찍어 흐렸음 —
  `Figure3D.k` 가 카메라 값을 그 배율만큼 키워 구도는 그대로). 숲의 나무줄기는 둘레를 18조각으로 잘게 나누고
  세로로 갈라진 **껍질 골** · 밑동의 이끼를, 우물 돌엔 잘게 팬 자국을 셰이더로 넣었습니다.
- **빛 번짐(블룸)** — 형광등 · 우물 입구의 빛 · 잎 사이 노을이 주변으로 은은하게 번집니다 (`PixFX.bloom` — 밝은 곳만 남겨
  1/6 로 줄여 흐린 뒤 `screen` 으로 두 겹. 캔버스 filter 를 못 쓰는 옛 사파리에선 건너뜀). 엔딩의 입체 방 · 실험실도 같습니다.
- 시스템의 **동작 줄이기**(prefers-reduced-motion)를 켜 두면 글리치가 약해지고 번쩍임(색 반전 · 검은 프레임 · 화면 미끄러짐 · 멈춤)과 잔글리치는 빠집니다.
- 오프닝이 끝나면 3D 화면들을 내려놓습니다(WebGL 문맥 해제). WebGL 이 없으면 예전 그림(2D)으로 그립니다.

## 🎬 엔딩 연출 순서

마지막 자물쇠의 대사가 네 박자로 끊기며, 한 줄마다 화면이 한 단계씩 더 무너집니다.

| 대사 | 화면 |
|---|---|
| `열쇠를 꽂는다. 딸깍.` | 딸깍 소리, 살짝 흔들림 |
| `…방이 **일그러진다.**` | 방이 물결처럼 일렁이기 시작 |
| `아니.` | 숨을 죽이듯 거의 멈춤 |
| `**화면이** 일그러진다.` | 화면이 찢어지고 색이 갈라짐 → 그대로 붕괴로 |

연출은 전부 `js/ending.js` 의 캔버스 한 장에서 그립니다 (라이브러리 없음).
**보스전을 끝낸 우물 안쪽에서 3D 로 넘어가 끝까지 이어집니다** — 오프닝(3D 실험실) → 우물 속 탑뷰(2D) → 다시 3D(엔딩 · 탈출).

0. **입체로 일어섬 (약 5.5초, `js/diorama3d.js`)** — 자물쇠를 연 그 탑뷰 화면이 멈춘 채 시작해,
   벽이 우르릉 솟고 카메라가 위에서 **주인공에게로 내려앉아 그 눈(1인칭)이 됩니다.** 바닥에 누운 주인공 그림은
   픽셀 덩어리째 흩어져 사라지고, **주인공이 보던 쪽 그대로**(오른쪽을 보고 있었으면 오른쪽) 앞을 봅니다 —
   마지막 방이면 눈앞에 그 문: 동쪽 벽을 채운 나무 문(색동 띠 · 태극 · 쇠 띠, 가운데 틈으로 새는 바깥 빛)과
   그 앞 잠금장치 기둥의 청록 불. 시야도 실험실과 같은 넓이로 벌어짐.
   마지막 시선은 **정면 대칭** — 문 · 태극 · 문틈의 빛 · 기둥이 화면 한가운데, 양옆 벽 높이와 빛도 좌우 똑같이.
   일어서는 내내 붕괴와 같은 **글리치 노이즈**(띠 밀림 · 블록 손상 · RGB 분리 · 노이즈 · 시스템 문구, 지직거림 + 치지직)가
   사이사이 튀고, 2D 로 보던 곳이 입체였다는 것 — 그 눈 그대로 아래 붕괴로.
   입체 방과 뒤의 3D 실험실은 화면의 2배 해상도로 그려 줄여 찍고(가장자리 계단 없이 매끈), 문틈 빛 · 형광등이 은은하게 번집니다.
1. **현실 붕괴 (약 5초)** — 그 1인칭 화면이 그대로 글리치로 무너진다.
   띠 밀림 · RGB 분리 · 노이즈가 차오르다 화면이 가로로 찢어지며 하얗게 날아가고,
   브라운관이 꺼지듯 선 → 점 → 정적.
2. **바이탈 (약 6.5초)** — 칠흑 속에 심전도 선이 그어진다. 던전의 형광 청록으로
   시작한 선이 첫 박동의 `삐—` 와 함께 터미널 녹색으로 식어 간다.
3. **모니터 밖 (약 6초)** — 심전도 화면이 걷히면 **3D 실험실**(`js/labroom.js` — 오프닝 · 탈출과 같은 방, 같은 침대)을
   07 의 눈으로: 누운 채 발치 너머를 반쯤 감긴 눈으로 보고, 형광등이 두어 번 튀며 켜진다.
   (WebGL 이 없으면 예전 픽셀 그림 — 카메라가 물러나면 그 심전도는 벽에 걸린 모니터였다.
   어두운 방엔 모니터 빛과 관찰창의 실루엣만 보이다가, 형광등이 두어 번 튀고
   켜지며 실험실이 드러난다 — 침대에 누운 피험자, 뇌파 캡과 오방색 전극선,
   링거와 붉은 배양액, 골격 모형, 키카드 잠금장치, 관찰창 너머의 연구원.)
4. **진실** — 터미널에 한 글자씩 찍힌다.
   `수면 상태 해제 중...` → `뇌파 연결 차단 완료.` →
   `수면 실험 종료. 피험자 07번, 의식 회복 확인.`
   다 찍히면 고개가 천장 쪽으로 넘어가고, 짧은 숨소리와 함께 **눈을 번쩍 뜬다** — 오프닝의 첫 화면이자
   탈출(제4막)의 첫 화면, 격자 조명이 있는 그 천장. (픽셀 판은 카메라가 얼굴로 다가가 피험자가 눈을 뜸)
   심박이 60 → 78 로 빨라진다.
5. 깜빡이는 커서와 `PRESS SPACE TO RETURN` → SPACE 를 누르면 `THE END` 카드 (`실험체 07 · 의식 회복 확인 — 세션 141 종료`,
   타임어택이면 클리어 타임 · 상위 3위 기록). **공개판은 1부까지** — 2부(제4막 1인칭 탈출)로 이어지는 길은 숨겨 두었고
   (`js/game.js` 의 `PART2_OPEN = false`, true 로 바꾸면 그 천장에서 그대로 탈출로 이어짐), 개발자 화면의 `탈출 …` 버튼으로만 들어갑니다.
   카드의 **처음부터 다시 (R)** — 버튼 · R · Enter 로 페이지를 새로 고치지 않고 타이틀로 (`restartFromEnd` — 아티팩트처럼
   다른 페이지 안에 들어간 화면에선 새로 고침이 막혀 버튼이 먹통이었음).

두 번째부터는 **길게 눌러 건너뛰기** — SPACE · Enter 나 화면을 약 1초 누르고 있으면 0~4 를 건너뛰고
눈을 뜬 마지막 장면(터미널은 다 찍힌 채)으로 바로 갑니다.

`prototypes/ending.html` 은 같은 `js/ending.js` 로 엔딩만 따로 돌려 보는 페이지입니다.
게임 화면 대신 무너지는 눈 보스(대역 던전)로 시작합니다.
`python3 build.py` 가 이것도 `dist/우물아래_엔딩.html` 한 파일로 묶습니다.

## 🧱 본편 도트 정리 (`js/pixfx.js`)

탈출(실사 3D)에 비해 본편이 "벡터 도형을 얹은 것처럼" 보이던 부분을 도트 게임답게 다시 정리했습니다.

- **잡몹 · 보스(눈) · 심연** — 곡선으로 그린 몸을 작은 캔버스에 그린 뒤 한 장의 도트 그림으로:
  반투명 가장자리를 계단으로, **1px 짙은 외곽선**, 위 가장자리엔 빛 · 아래엔 그늘(도트 그림의 기본 음영),
  맞으면 **흰 실루엣**으로 깜빡임. 잡몹은 1.15배 — 어두운 방에서도 실루엣이 읽힘.
  눈 보스의 숨 쉬는 크기는 2픽셀 단위로만(소수 배율로 늘이면 픽셀이 일렁였음).
- **탄** — 흐린 빛무리 대신 꽉 찬 도트 탄: 짙은 테 · 몸 · 왼쪽 위 한 점 빛 (적 탄은 속이 두 박자로 깜빡임).
- **충격파 고리 · 심연의 예고 고리 · 내리찍기 표시 · 촉수 · 낫 궤적** — 한 겹에 모아 그린 뒤
  반투명은 **4×4 체크 디더**(옛 도트 게임의 반투명), 아주 옅은 건 버림(점 무늬로 지저분해지지 않게), 가장자리는 계단.
- **그림자** — 매끈한 타원 대신 줄마다 정수 폭으로 채운 도트 타원 (주인공 · 잡몹 · 보스 · 나무 · 우물).
- **튀는 조각 · 죽을 때 흩어지는 숫자** — 정수 픽셀로, 숫자는 흐린 빛번짐 대신 1px 짙은 테 + 청록 그림자 한 칸.
- **실험실 타일이 비치는 바닥(갈림길 · 탈출구 …)** — 반투명 회색 격자 + 가는 벡터 선이 임시 그림처럼 보였던 것 →
  돌이 깨져 나간 들쭉날쭉한 구멍(짙은 테 · 빛 받은 깨진 면) 아래 한 단 낮게 흰 타일(줄눈 · 얼룩 · 금 · 돌이 드리운 그늘).
- **숲의 나무 · 덤불** — 동그라미 두 개였던 잎을 잎 덩어리 여럿(짙은 바탕 · 가운데 톤 · 왼쪽 위 빛) · 잎 낱알 · 외곽선으로,
  줄기엔 껍질 결 · 뿌리. 한 번 구워 두고 찍음.
  바람 — 잎 덩어리가 통째로 미끄러지지 않고, 줄기에 붙은 아래는 그대로 · 위로 갈수록 휘어짐(가로 띠마다 정수 픽셀로 밀어 그림, 꼭대기 최대 2~3픽셀).
  바람은 숲을 왼쪽에서 오른쪽으로 쓸고 지나가는 물결(나무마다 박자가 조금씩 늦음) + 몇 초에 한 번 돌풍, 풀도 같은 바람에.
- **숲의 우물** — 매끈한 타원 테두리를 돌 열네 개로 쌓고, 구멍은 안쪽 벽이 몇 단으로 어둠에 사라지게. 기둥 빛 · 기와 결.

그리는 비용은 한 장에 1~2ms 정도 늘었습니다. pixfx.js 가 없으면 예전처럼 그립니다.

### 잡몹 만들기

"메이플 버섯처럼 귀엽다"는 인상을 없애기 위해 `tools/make_assets.py` 가
원본을 다음 순서로 가공합니다.

1. 버섯 **대(얼굴) 영역**을 연결 요소로 찾고
2. 그 안쪽에 **갇힌 구멍**(동그란 눈 · 미소 · 볼터치)만 살색으로 메운 뒤
   — 갓의 어두운 밑면은 바깥과 이어져 있으므로 건드리지 않습니다
3. 전체를 어둡게 낮추고 보랏빛 슬레이트로 물들이고
4. **처진 눈매 · 붉은 홍채 · 톱니 이빨**을 픽셀로 다시 그립니다

게임에서는 여기에 **어둠 속에서 번들거리는 눈빛**과 발밑의 기운을 얹습니다.

```bash
python3 tools/make_assets.py <업로드폴더>   # assets/*.png + js/assets.js 재생성
```

## ☣ 연구소 사람들 — 실사 3D (`js/figure3d.js`)

탈출에서 쫓아오는 박사와 앞을 막는 경비원, 오프닝에서 들여다보는 의사 · 지나가는 조수 · 숲의 그림자는 **WebGL 로 그린 3D 인물**입니다.
복도는 픽셀 그대로 두고, 사람만 화면 해상도로 실제 조명을 받아 그 사이에 끼워 넣습니다 — 픽셀 버퍼를
인물 앞뒤 겹으로 나눠 두었다가 겹 → 3D 인물 → 다음 겹 순서로 쌓으므로, 더 가까운 장애물 · 총 · 붉은
테두리는 인물을 그대로 가립니다. 복도와 같은 안개 · 경보의 붉은 맥박 · 형광등 깜빡임 · 화면 기울기와 흔들림을 받습니다.

- 몸은 마디(몸통 · 위팔 · 아래팔 · 손 · 넓적다리 · 정강이)마다 따로 만든 메시를 관절 행렬로 움직입니다 —
  추격자는 달리며 가까워질수록 장갑 낀 두 손을 눈높이로 뻗고, 경비원은 두 손으로 권총을 겨눕니다.
- 큰 주름은 모양으로(소매 · 바짓단은 아코디언처럼, 접힌 골짜기는 어둡게), 잔구김 · 묵은 얼룩은 셰이더 잡음으로.
  몸을 캡슐 열두 개로 어림해 겨드랑이 · 다리 사이 · 후드 밑처럼 서로 가리는 곳의 **그늘을 미리 구워** 둡니다.
- **방호복** — 형광등 아래 바랜 카키 노랑, 청회색 고무 장갑 · 장화(광택), 손목 · 발목 회색 밀봉 테이프,
  후드 속 **새까만 보호면**(얼굴은 끝까지 보이지 않고, 복도 천장 형광등이 비스듬히 비침)과 고무 테두리,

   낮춥니다. WebGL 이 없으면 예전 픽셀 복도.

   가까워질수록 화면 가장자리가 붉어지고 심장 소리가 빨라지며, 앞을 보고 있어도 그의 그림자가 발치까지 늘어집니다.

   **🔫 중간 총격전 (286~450m)** — 바닥에서 빛나는 권총을 주우면 `경비원 같은데…`

## 🧍 주인공 — 시안 G '지금 + 글리치' (`js/heroart.js`)

실험실의 어느 한 곳이 꿈속에서 일그러진 모습입니다.

**바닥 재질** (`js/floors.js`) — 예전엔 모든 방이 32px 정사각 타일 격자였습니다. 이제 방마다:
우물 아래 젖은 **자갈** · 갈림길/관문 크기가 제각각인 **판석**(금 · 깨진 모서리) · 병동 작은 **병원 타일**
(빠진 타일 · 때) · 수조실 **젖은 타일** · 관측실 리벳 박힌 **철판** · 뿌리 통로 다져진 **흙** · 기록 보관실
**나무 마루**(나뭇결 · 옹이 · 못) · 심층 가운데를 둘러 쌓은 **원형 돌 바닥** · 탈출구 실험실 **리놀륨**.
마지막에 픽셀마다 거칠기와 벽가로 갈수록 끼는 때를 얹습니다. 방 하나 굽는 데 30~60ms.

장애물은 실제로 막아섭니다 — 주인공 · 적은 발자리에서 밀려나고(돌진하다 부딪히면 멈칫),
총알은 부딪혀 사라집니다. 주인공보다 뒤에 선 것은 먼저, 앞에 선 것은 나중에 그려
기둥 · 서류장 뒤로 돌아가면 가려집니다. 문 앞길과 적 · 상자 · 열쇠 자리는 비워 두었고,
모든 방에서 문 · 상자 · 열쇠까지 길이 이어지는지 길 찾기로 확인했습니다.
적은 장애물에 막히면 **모서리를 따라 돌아갑니다** (`propSlide` — 예전엔 침대 뒤의 주인공 쪽으로 곧장 밀기만 해서
북쪽 병실 침대에 붙어 멈춰 있었음). 돌아갈 쪽은 가려던 쪽에 가까운 쪽 · 애매하면 모서리가 가까운 쪽, 한동안 유지하고 벽에 막히면 반대로.

**심연 체크포인트** — 보통 · 어려움에서 페이즈3 「심연」과 싸우다 죽으면 사망 화면 버튼이
`심연부터 다시 (R)` 로 바뀌고, 누르면 눈을 다시 잡을 필요 없이 심연부터 싸웁니다
(심연 체력 가득 · 늘어난 체력칸 가득 · 심연에서 먼 벽가에서 시작 · 브금은 도입 없이 바로).
눈과 싸우다 죽으면 지금처럼 보스방 처음부터, 타임어택은 언제나 처음부터입니다.

쉬움의 보스는 페이즈2·3을 **같은 폭으로** 낮췄습니다 (각각 체력 −15% 를 더하고 위 배율을 똑같이).

### 넓어진 보스방

보스방(심층)만 화면(576×324)보다 넓은 **768×432** 입니다 (`js/rooms.js` 의 `size`). 방이 화면보다
넓으면 카메라가 주인공을 따라가되 보스 쪽으로 30% 당겨서 보스가 되도록 화면 안에 있게 하고,
보스 등장 · 변이 · 심연의 최후 동안엔 그 자리 쪽을 봅니다. 미니맵 · 보스 체력바 · 섬광 같은
화면 위의 것은 그대로 화면에 붙어 있습니다. 바닥의 둥근 의식 원 · 케이블 · 항아리 자리도 방 크기에 맞춰 넓어졌습니다.

**보통**은 넓은 방에서 제대로 긴장되도록 — 자주 · 빠르게 · 촘촘하게 쏘고, 페이즈2부터 원형 포자가
**두 겹**으로 날아옵니다(겹마다 반 칸씩 돌아서 빠져나갈 틈이 옮겨 감, 약 0.23초 간격).
예비 동작은 ×0.9 로 조금만 줄여 보고 피할 틈은 남겼습니다.
**어려움**은 '하트 한 칸 남기고 겨우' 깨는 걸 목표로 — 쉴 틈 없이 몰아치고, 원형 포자는 페이즈1부터
두 겹 · 페이즈2부터 세 겹, 예비 동작은 ×0.82(눈 약 0.44초)까지만 줄였습니다. 체력칸은 그대로라
페이즈가 바뀔 때 떨어지는 하트를 놓치면 버티기 어렵습니다. **쉬움**은 지난번 그대로입니다.
타임어택은 언제나 '보통'이라, 이 변경 전 기록과는 보스전 난이도가 다릅니다.
