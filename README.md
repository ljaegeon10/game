# 우물 아래 — The Well Below

평화로운 지상에서 우물로 **추락**하고, 아이작 스타일의 기괴한 지하를 지나
**"이 모든 것이 꿈(연구 프로젝트)이었다"** 는 반전으로 끝나는 4분짜리 2D 탑뷰 웹게임입니다.

HTML · CSS · 순수 JavaScript(Canvas 2D)로만 만들었고, 외부 라이브러리가 없습니다.

---

## ▶ 실행 방법

### 가장 쉬운 방법 — 단일 파일
`dist/우물아래.html` **한 파일만 내려받아 더블클릭**하면 됩니다.
CSS·JS·이미지가 전부 안에 들어 있어서 인터넷도, 서버도 필요 없습니다.

### 개발용 (파일이 나뉜 버전)
저장소를 받은 뒤 `index.html` 을 브라우저로 열면 그대로 실행됩니다.
수정한 내용을 단일 파일로 다시 묶으려면:

```bash
python3 build.py      # → dist/우물아래.html 생성
```

> 권장 브라우저: Chrome / Edge / Firefox 최신 버전. 소리는 화면을 한 번 클릭해야 켜집니다.

## 🗺 복선(떡밥) 연결 고리

지하에서 마주치는 기괴한 요소는 전부 **현실(연구실)의 사물이 왜곡된 것**입니다.
엔딩에서 이 대응 관계를 한 줄씩 짚어 줍니다.

| 지하 던전 (꿈) | 현실 연구실 (진짜 모습) |
|---|---|
| 바닥에 흩어진 해골과 뼈 | 구석에 쌓여 있는 인체 골격 모형 |
| 사방에 흩뿌려진 피와 핏방울 | 몸에 꽂힌 링거 호스와 붉은 배양액 |
| 방을 잠그는 '열쇠'와 '상자' | 실험 장치의 '키카드'와 '잠금장치' |
| 기괴한 몬스터 / 슬라임 | 모니터에 출력되는 뇌파 그래프·세포 이미지 |
| 던전 벽의 단청 격자 | 천장 조명 격자 |

### 게임 안에 심어 둔 장치

- **지상의 이질감** — 평화로운 새소리 밑에 환풍기 소리가 계속 깔리고, 아주 가끔
  숲과 어울리지 않는 **기계 비프음**이 울립니다. 나비도 이따금 한 프레임 **튑니다**.
- **날짜가 뛴다** — 방을 하나 넘어갈 때마다 HUD의 `LOG DATE` 와 벽 낙서가
  `5/1 → 5/5 → 5/10 → 5/20` 으로 건너뜁니다.
  *"내가 방을 옮기는 게 아니라, 시간이 흐르며 실험이 깊어지고 있다."*
- **시스템 에러** — 몬스터를 처치하면 피가 튀는 대신 **노이즈와 함께 코드 조각·뇌파
  그래프**로 흩어집니다.
- **무너지는 단청** — 오방색 단청 무늬가 깊이 내려갈수록 흐려지고 각도가 어긋납니다.
- **쪽지 2장** — 기획안의 2145/5/1, 2145/5/15 쪽지가 문장 중간에서 끊겨 있습니다.

## ⚖️ 밸런스 (플레이 타임 4분 기준)

수치는 전부 `js/rooms.js` 의 `BALANCE` 에 모아 두었습니다.

| 항목 | 값 | 비고 |
|---|---|---|
| 플레이어 체력 | 6 | 피격 후 0.9초 무적 |
| 이동 속도 | 2.15 px/f | 약 129 px/s, 방 하나를 3.2초에 횡단 |
| 연사 | 21프레임 | 초당 약 2.85발, 발당 1 데미지 |
| 버섯 | HP 3 / 속도 0.72 | 근접 추격 |
| 포자 버섯 | HP 4 / 속도 0.45 | 2.2초마다 포자 발사, 거리 유지 |
| **보스(눈)** | **HP 56** | 실효 DPS 약 1.5 기준 **40~55초** |

**보스 3단계 구성**

1. **1페이즈 (100~66%)** — 느린 추격 + 2.5초마다 8방향 포자. 예고 동작 32프레임.
2. **2페이즈 (66~33%)** — 12방향 포자에 **돌진**이 섞임. 속도 1.15배.
3. **3페이즈 (33~0%)** — 속도 1.5배, **나선탄** 지속 발사, 잡몹 2마리 소환.

페이즈가 바뀔 때마다 체력이 깎여 있으면 **하트를 하나 흘립니다.**
방마다 놓인 항아리도 50% 확률로 하트를 떨어뜨려, 4분 안에 끝낼 수 있게 조정했습니다.

### 진행 구조 (약 4분)

```
지상(숲) 40s → 1방 45s → 2방 40s → 3방 45s → 보스방 55s → 마지막 문 + 엔딩 28s
```

| 방 | 날짜 | 열쇠 획득 방식 |
|---|---|---|
| 1방 | 5 / 1 | 바닥의 열쇠 → 상자 → **쪽지 1** + 문 열쇠 |
| 2방 | 5 / 5 | 적 전멸 → 문 열쇠 |
| 3방 | 5 / 10 | 적 전멸 → 상자 열쇠 → 상자 → **쪽지 2** + 문 열쇠 |
| 보스방 | 5 / 20 | 보스 처치 → 마지막 열쇠 |
| 마지막 방 | 5 / 20 | 잠금장치에 열쇠 → **엔딩** |

> 바닥·전멸로 얻은 열쇠로는 문이 열리지 않습니다. **"다음 방 열쇠"** 를 손에 넣어야만
> 문이 열리므로 상자와 쪽지를 건너뛸 수 없습니다.

## 🎬 엔딩 연출 순서

1. 마지막 열쇠를 꽂는 순간 **모든 불이 꺼지고** 지속 기계음(삐————)이 깔린다
2. 암전 위로 `실험체 뇌파 안정화 단계 진입` 이 타자기처럼 출력된다
3. **눈꺼풀이 스르륵 열리듯** 화면 위·아래가 갈라진다
4. 도트가 아닌 **SF 연구실**이 드러나고 카메라가 6.5초에 걸쳐 **줌아웃**된다
   (침대에 누운 실험체, 링거, 뇌파 모니터, 골격 모형, 키카드 잠금장치, 연구원 실루엣)
5. **꿈 → 현실** 대응이 한 줄씩 지나간 뒤 `THE END`

## 📁 구조

```
index.html          화면 구조 (HUD · 쪽지 · 엔딩 연구실 전부 HTML)
css/style.css       오방색 팔레트, CRT/글리치, 쪽지, 엔딩 연구실 (전부 CSS)
js/assets.js        픽셀아트 4종을 base64 로 내장 (file:// 실행용)
js/audio.js         WebAudio 합성 효과음 — 음원 파일 없음
js/art.js           단청·색동·매듭·태극, 숲/던전 배경 절차적 생성
js/rooms.js         스테이지 구성 · 스토리 텍스트 · 밸런스 수치
js/game.js          게임 루프, 전투, 보스 AI, 연출
assets/             원본 PNG 4종 (pig / mushroom / eye / brick)
build.py            단일 HTML 파일로 묶는 스크립트
dist/우물아래.html   ← 배포용 단일 파일
```

## 🎨 사용된 픽셀아트

제공해 주신 Piskel 4종을 그대로 사용했습니다.

| 파일 | 게임 내 역할 |
|---|---|
| `pig.png` | **플레이어** (붉은 리본 돼지) |
| `mushroom.png` | **잡몹** — 버섯 / 색을 돌린 포자 버섯 |
| `eye.png` | **보스** — 보랏빛 화염에 싸인 눈 |
| `brick.png` | 던전 **벽 텍스처** |

> 돼지 스프라이트는 원본에 투명 체크무늬 배경이 픽셀로 구워져 있어,
> 가장자리에서 플러드 필로 걷어낸 뒤 사용했습니다.
