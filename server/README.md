# 축제 기록 서버 설치 (구글 시트 + 앱스 스크립트)

GitHub Pages 에 올린 축제판(`docs/`)이 기록을 보내는 곳입니다.
로그인 없이 누구나 기록을 남기고, **연락처는 내 구글 시트에만** 쌓입니다. 10분이면 끝나요.

## 1. 구글 시트 만들기
1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만들고 이름을 `우물아래 축제 기록` 정도로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.

> **아이패드 · 휴대폰** — 구글 시트 *앱*에는 Apps Script 메뉴가 없습니다. Safari 에서 [script.google.com](https://script.google.com) 을 열고
> **새 프로젝트** 를 만든 뒤 아래 2 · 3 단계를 그대로 하면 됩니다 (코드 맨 위 `SHEET_ID` 에 시트 주소의 id 가 들어 있어야 함).
> 화면이 좁아 메뉴가 안 보이면 Safari 주소창의 `가가`(aA) → **데스크톱 웹사이트 요청**.

## 2. 코드 붙여 넣기
1. 열린 편집기의 `Code.gs` 내용을 전부 지우고, 이 폴더의 `apps_script.gs` 내용을 통째로 붙여 넣은 뒤 💾 저장.
2. (선택) 순위판에 PIN 을 걸고 싶으면 맨 위 `const BOARD_PIN = '';` 의 따옴표 안에 숫자를 넣습니다. 예: `'2580'`
3. 위쪽 함수 고르는 칸에서 **`setup`** 을 고르고 **▶ 실행**.
   - 처음엔 "권한 검토"가 뜹니다 → 내 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → 허용.
     (내가 만든 스크립트라 구글이 확인을 안 한 것뿐이에요.)
   - 시트에 `기록` · `연락처` 탭이 생기면 성공.

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택.
2. 설정:
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** ← 이걸 해야 로그인 없이 기록이 남아요
3. **배포** → 나온 **웹 앱 URL**(`https://script.google.com/macros/s/……/exec`)을 복사.

## 4. 게임에 주소 넣기
1. GitHub 저장소에서 `docs/festival-config.js` 를 열고 ✏️(편집).
2. `window.WB_SERVER = '';` 의 따옴표 안에 복사한 주소를 붙여 넣고 커밋.
   ```js
   window.WB_SERVER = 'https://script.google.com/macros/s/……/exec';
   ```
3. 1~2분 뒤 GitHub Pages 주소를 새로고침하면 끝.

## 쓰는 법
- 타임어택을 고르면 이름 · 연락처를 받고, 클리어하거나 죽으면 바로 순위판에 올라갑니다.
- 타이틀 오른쪽 위 **실시간 순위판** (주소 끝에 `#board` 를 붙여도 바로 열림) — 4초마다 갱신.
- **연락처 · 전체 기록은 구글 시트에서** 봅니다. 시험 기록이나 이상한 기록은 시트에서 그 줄을 지우면 순위판에서도 사라져요.
- 축제가 끝나면 `연락처` 탭을 지워 주세요 (참가 등록 때 "축제가 끝나면 지워요"라고 약속했어요).

## 순위판 고치기 (`순위판 설정` 탭)
순위판 오른쪽 아래 **✏️ 수정** 을 누르면 이 탭이 바로 열립니다 (`docs/festival-config.js` 의 `WB_SHEET`).
코드가 처음 순위판을 불러올 때 시트에 `순위판 설정` 탭이 생깁니다. **`값` 칸만 고치면 몇 초 뒤 순위판에 그대로** 바뀌어요 (다시 배포할 필요 없음).
| 항목 | 하는 일 |
|---|---|
| 동아리 이름 · 제목 · 부제 | 맨 위 글 (비우면 원래 글) |
| 보여줄 등수 | 3 ~ 30 |
| 상품 안내 · QR 문구 | QR 옆 글 |
| 1등 · 2등 · 3등 상품 | 순위판 1~3등(클리어한 사람) 이름 밑에 🎁 로, QR 옆에도 한 줄로 |
| 공지 | 화면 아래로 흐르는 빨간 띠 (비우면 없음) |
| 개발자 기록 | 순위와 따로 목록 위에 나오는 기록 — 예 `장도우 1:38.78` (비우면 `festival-config.js` 의 `WB_DEV`) |
| 순위판 PIN | 숫자를 넣으면 그 PIN 을 알아야 순위판을 봄 |
기록을 고치거나 지우는 것도 `기록` 탭에서 그 줄을 고치거나 지우면 순위판에 바로 반영돼요.

## 알아 둘 것
- 웹 앱 주소는 게임 안에 들어 있어서 마음먹으면 누구나 가짜 기록을 보낼 수 있어요.
  서버가 이름 · 번호 모양, 시간 범위(1분 안 클리어는 거절)를 검사하지만, 이상한 기록은 시트에서 지워 주세요.
- 코드를 고쳤다면 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 해야 반영돼요 (주소는 그대로).
